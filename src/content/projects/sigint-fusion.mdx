## Problem & constraints

Modulation classification is a solved-looking problem with an unsolved data problem: the good
datasets are licensed, and the tempting shortcut is to generate your own I/Q and pretrain on it.
This project was built to run that shortcut properly and report what it actually bought.

The platform constraints were separate from the model question. Nine services, health-checked,
with a **validated Java ingest boundary** in front of the model - because in a signals pipeline
the malformed capture is not an edge case, and a Python consumer should never be the first thing
to see one.

## Results

On real DeepSig RadioML 2018.01A the ResNet-1D reaches **75.7% top-1** across 21 modulations over
an SNR range of -10 to 30 dB, rising to 94% at 10 dB and 96% at 30 dB. Five-shot transfer to
three modulations never seen in training reaches **87.6% ± 4.3** over 50 episodes against a 33%
chance baseline.

The serving path holds up: **1.48 ms** model-only p50 and **251 req/s** at 32 concurrent requests
on CPU ONNX Runtime, with an end-to-end p50 of 110 ms across the full HTTP path. Retrieval reaches
**hit@5 100% and MRR 0.93** over 53 questions with hybrid dense + full-text, against 98.1%
dense-only, and the LangGraph analyst completed 10/10 tasks on a local qwen2.5:7b.

## Ablations

**The headline result is a negative one, and it is the point of the project.**

Pretraining on my own synthetic channel model and fine-tuning on real frames scored **-0.4 pp**
against training from scratch at full data, and **-4.1 pp** at 10% data. Frozen synthetic features
reached only ~71% where real-trained features reached ~87%. A synthetic generator that matches the
class list and the file layout of a real dataset produces a working *pipeline* and a
non-transferring *representation*, and those two things are easy to confuse if you only ever run
the pipeline.

Two more routes were tried and lost. BYOL self-supervision came in at **-2.7 pp** at 10% data. A
ViT-tiny over STFT spectrograms reached **48.6%** against the ResNet-1D's 75.7% on the same split -
treating I/Q as an image throws away the phase structure the 1D model uses directly.

Every table in the repo is written by a script into a results JSON carrying dataset path, a
synthetic flag, GPU, seed and git commit, and rendered from there. Nothing in them is typed by hand.
