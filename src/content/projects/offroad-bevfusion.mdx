## Problem & constraints

Off-highway perception has the same sensor set as automotive and almost none of the data. The
constraint here was a zero-cost GPU budget: one shared NVIDIA L4, nuScenes-mini for training, and
GOOSE for the off-road transfer check. Under those constraints absolute accuracy is meaningless,
so the project was built to measure *deltas* - what each modality adds, what happens when one
drops out, what the export path costs - and to make the deployment real rather than a notebook.

The export constraint drove the architecture: static-shape ONNX at opset 17 with **no custom
TensorRT plugins**, so the engine builds on a stock TensorRT install and the ROS 2 node does not
depend on a patched runtime.

## Results

TensorRT FP16 takes the graph from **36.4 ms to 15.2 ms** on an L4, and the deployed ROS 2 Humble
C++ node runs the whole frame in **11.5 ms** on that engine. On accuracy, each modality pays for
itself: camera-only reaches mAP 0.022, adding LiDAR 0.047, adding radar 0.053, with BEV
segmentation mIoU moving 0.214 → 0.283 → 0.302 over the same steps.

## Ablations

The radar-dropout study is the one that changed my mind about the design. Dropping radar at test
time - after training with it - takes mAP from **0.053 to 0.008 at 50% dropout and 0.001 at
100%**. The fused model does not degrade gracefully; it has learned to depend on a sensor it was
never taught to lose. That is a training-time fix (modality dropout augmentation), not a
deployment-time one, and it is listed as open work rather than quietly omitted.

Two other ablations cut against the headline and are reported anyway: removing deformable
attention *raised* mAP to 0.059, and fixed loss weights beat the learned Kendall weighting at
0.062. On a dataset this small those differences are inside the noise, which is exactly why the
deltas are reported with the dataset size attached.

On GOOSE, zero-shot drivable-area IoU is **0.021** and fine-tuning takes it to **0.348** - a
plain statement that a nuScenes-trained BEV head transfers almost nothing to off-road terrain.
